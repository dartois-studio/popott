Comment marche le suivi projet ?

1. À quoi ça sert

C’est ta liste centrale d’idées de features, de bugs et d’améliorations pour {{name}} — à la place des bloc-notes et des tâches éparpillés. Tu notes, l’IA lit et transforme en plans d’action + PR.

2. Remplir une entrée

Titre + Type + Catégorie + Priorité (P0→P3) + Statut. L’IA qui réalise le code renseigne normalement elle-même Codé avec. En éditant un ticket existant, le champ IA utilisée — correction manuelle permet toutefois de corriger un oubli ou de saisir librement une autre IA. Pour une capture : fais un screenshot puis Ctrl+V n’importe où — elle s’attache à l’entrée en cours.

3. Où vont mes données (sauvegarde)

Automatique, à chaque changement. Deux cas :

  • Sans rien faire : gardé dans ton navigateur (invisible pour Claude, mais conservé même si tu fermes l’onglet).
  • Recommandé (Chrome/Edge) : clique « Connecter .claude » en haut, une fois, et choisis le dossier .claude. L’app écrit alors de vrais fichiers : suivi.json (les données — léger : les captures y sont de simples références), suivi.md (version lisible par Claude) et les captures en PNG dans suivi-captures\.

Reconnexion & anti-perte : aux fois suivantes, la page se reconnecte toute seule si le navigateur l’autorise ; sinon la pastille passe en orange « Déconnecté — clique pour reconnecter ». Et si tu avais saisi des choses hors-connexion, rien n’est écrasé en silence : la page affiche un mini-journal des différences entre tes saisies et le suivi.json du disque, tu choisis quelle version garder, et l’autre est toujours sauvegardée (suivi.backup-….json).

4. Comment Claude lit et utilise ça

Tu lui dis simplement « regarde le suivi ». Claude Code ou ChatGPT ouvre .claude\suivi.md : il voit le résumé chiffré, chaque entrée avec son ID ({{prefix}}-014), les lots, l’outil qui a réalisé le code et les captures qu’il peut vraiment ouvrir. Il te propose des lots calibrés pour une PR, tu valides, il code.

5. Les lots (paquets de PR)

Un lot regroupe des issues qui tiennent dans une seule PR cohérente. En pratique : l’agent propose le découpage (selon ce qui est faisable d’un coup), tu valides. Tu peux aussi créer un lot toi-même via ⚙ gérer.

6. Statuts & mise à jour « auto »

À faire → En cours → En PR → Fait (+ Parké)

Claude Code et ChatGPT écrivent dans le même suivi.json : au terme du code, l’IA renseigne Codé avec sur chaque ticket. Un ticket ne peut pas passer en « Fait » tant que cette attribution manque, mais l’avertissement du Planning est cliquable et ouvre la correction manuelle. Le passage en « En PR » signifie que le ticket attend TON merge, puis {{checkPhrase}}.

7. S’y retrouver / trier

  • 4 vues : Cartes, Liste, Kanban (glisse une carte d’une colonne à l’autre pour réaffecter la valeur de la colonne — statut par défaut), et Planning.
  • Planning : roadmap des lots. Chaque carte affiche les IA utilisées à partir de ses tickets. Les colonnes sont déduites des PR GitHub via sync-pr.ps1 : Planifié → En cours → En PR → {{stageMerged}} → {{stageDone}}. L’icône ⧉ copie le prompt à coller dans l’IA ; « {{markBtn}} » après {{checkPhrase}} passe le lot en {{stageDone}} et ses entrées en « Fait ».
  • 📌 Décisions : chaque lot garde ses décisions validées (design, périmètre…) — Claude les note pendant les sessions, ou toi via ＋ décision (au survol de la carte ; double-clic sur une décision pour la supprimer). Elles évitent de re-débattre un choix déjà tranché.
  • Pastille de stats (en haut) : PR mergées sur 7 jours · cycle moyen création→{{participle}} · {{noun}}s en attente. Un clic ouvre un pop-up avec les graphiques détaillés (statuts, priorités, étapes des lots, tendance des PR mergées).
  • Filtres : recherche, catégorie, type, lot, priorité, statut et Codé avec. Filtre « En PR » = tout ce qui attend ton merge.
  • Grouper par : statut, catégorie, type, priorité, lot ou Codé avec — pilote les en-têtes de groupe (Cartes & Liste) et les colonnes du Kanban.
  • Tri (Cartes) : priorité, récent, catégorie. En Liste, clique les en-têtes de colonnes.
  • Colonnes (Cartes) : Auto / 1 / 2 / 3. Dupliquer : l’icône ⧉ sur chaque carte ou ligne crée une copie.

8. Exporter (si dossier non connecté)

Les boutons ⬇ Exporter .md / .json en bas téléchargent le fichier à donner à Claude. Inutile si tu as connecté le dossier .claude (l’écriture est alors automatique).
